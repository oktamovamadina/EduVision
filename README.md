# EduVision Analitika Platformasi

Mavzu: Interaktiv vizualizatsiya dashboardi — Plotly yordamida

Bu versiyada xatoliklar tuzatildi:
- `ID not found in layout` xatosi bartaraf etildi.
- Barcha menyu va matnlar o'zbek tiliga o'tkazildi.
- Dash + Plotly platforma uslubi saqlandi.

## Ishga tushirish

```bash
pip install -r requirements.txt
python app.py
```

Brauzerda ochish:

```text
http://127.0.0.1:8050
```
